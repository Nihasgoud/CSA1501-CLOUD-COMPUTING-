## Short CO1 reflection
CampusIQ shows how virtualization, web services and layered service models combine into a scalable, cost-aware solution. Managed compute (Fargate, Lambda) and managed data services (RDS, S3, Cognito) carry operational work, a REST API behind a gateway gives a controlled entry point, and six independent scaling points absorb spiky demand while the shared-responsibility boundary stays clear.
